# YouTube Homepage Clone

This project is a **static clone of the YouTube homepage**, built using only **HTML** and **CSS**. It replicates the basic structure and styling of YouTube's home interface to practice front-end web development skills.

## 🔍 Features

- Responsive layout (optional: add responsiveness with media queries)
- Header with logo, search bar, and profile icons
- Sidebar navigation (Home, Trending, Subscriptions, etc.)
- Video thumbnails in grid layout
- Hover effects and modern styling using CSS

## 🛠️ Technologies Used

- HTML
- CSS (Flexbox and Grid)
